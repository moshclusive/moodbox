# Contributing to MoodBox

Thanks for helping make MoodBox better. Contributions for the desktop app are bug reports, ideas and documentation improvements.

## How to Contribute

1. **Report a bug.** Open an issue and describe what you did, what you expected, and what happened instead. Add the MoodBox version and your Windows version.
2. **Suggest a feature.** Open an issue and explain the problem it solves and how you would use it.
3. **Improve the docs.** Open an issue describing the change, or a pull request with the corrected text. Small fixes (typos, unclear steps, missing examples) are welcome.
4. **Fix the browser extension.** The extension files are in `extension/` - fixes and improvements to the extension are welcome as pull requests. Keep the change focused, one fix per pull request.

## Reporting Bugs Well

A good bug report includes:

- The MoodBox version and whether you used Setup or Portable
- What you clicked, in order, and what happened
- What you expected vs. what actually happened
- A screenshot if it helps

## Code of Conduct

Be kind and respectful. No spam, no self-promotion, no unrelated links.
